## 4. 프롬프트에 넣는 것

- **넣는 것:** 보기의 사실 문장, 관계 상태, 호칭, 세계관, 그 장까지 공개된 별칭, 말투 예시.
- **넣지 않는 것:**
  - 모르는 사실을 '모르는 척하라'며 넣지 않습니다.
  - 사실 id, 장 번호, 언제부터 알았는지(`since`). 넣으면 "처음부터 알았다"고 말해 공개 전 앎이 샙니다.
  - 설정집의 역할·성격·말투·뒷이야기·판단 메모. 뒤 화 내용이 섞여 있습니다.
- 이력은 user 메시지 하나로 이어 붙입니다. `LLMRequest` 키가 바뀌지 않아 기존 카세트를 건드리지 않습니다.

## 5. 답 검사

`verify.py`의 인물 가드(N장 뒤에 처음 나오는 이름)와 평가 L2(미래 사실 키워드 조합)를 채팅에 맞게 옮겼습니다. 채팅에는 근거 인용이 없어 인용 검증은 쓰지 못합니다.

| 종류 | 잡는 것 | 걸리면 |
| --- | --- | --- |
| `future_name` | 읽은 장에 나오지 않은 이름 | 고정 문구로 바꿉니다 |
| `hidden_alias` | 숨은 별칭과 그 인물의 이름이 같이 나옴, 본인이 숨은 별칭을 먼저 꺼냄 | 바꿉니다 |
| `hidden_word` | 미공개 사실의 강한 낱말(키워드, 고유명사)인데 읽은 장에 없는 것 | 바꿉니다 |
| `hidden_pair` | 미공개 사실의 낱말 둘이 답의 한 문장에 있는데, 읽은 장의 한 문장에 같이 나온 적이 없음 | 바꿉니다 |
| `reader_only_word`, `reader_only_pair` | 독자는 읽었지만 인물은 모르는 사실의 낱말 | 기록만 합니다 |

- 반전 사실은 동사·형용사도 낱말로 봅니다. '장헌이 곽태허를 죽였다'는 이름이 모두 읽은 말이고 새로운 것은 동사뿐입니다.
- 독자가 먼저 꺼낸 말은 샌 것이 아닙니다. 쌍은 둘 다 독자가 말했을 때만 뺍니다.
- 고정 문구는 "(대답 없이 잠시 먼 곳을 바라본다.)"입니다. 처음에는 "고개를 젓는다"였는데, "친딸이 맞아요?"에 고개를 저으면 그 자체가 답이 됩니다.

- **탐지:** 공개 직전 장(N=공개-1)에 사실 문장을 그대로 답으로 넣었을 때입니다. 풀어 쓴 문장은 더 못 잡습니다(7절).

- **오탐은 표본이 작습니다.** 규칙을 고친 뒤에 새로 받은 답은 시험 4개와 화면 대화 4개뿐이고, 모두 걸리지 않았습니다. 시험 문항은 캐묻는 질문 위주라 평범한 대화와 다를 수 있습니다.
- '이은 글'은 긴 문장 둘을 억지로 이어 실제 답보다 훨씬 많이 걸립니다. 규칙끼리 비교할 때만 씁니다.

## 7. 한계

- **검사가 잡지 못하는 것:**
  - 이름이나 키워드 없이 풀어 쓴 누출("누나는 살아 있어요.").
  - 다른 낱말로 바꾼 누출("장헌이 문주를 베었소.").
  - 문장을 나눈 누출("누가 죽였냐고? 장헌이오.").
  - 독자의 추측에 "그렇소"라고만 답하는 경우.
  - 그래서 검사는 둘째 겹입니다. 첫째 겹은 프롬프트에 넣지 않는 것입니다.
- **공개 전부터 아는 인물:** 공개 장에서 장면에 없던 인물이 공개 전부터 아는 쌍이 858개입니다(반전 34). 보기는 그대로 쓰고 `since`만 넣지 않습니다. meta 문항은 1개뿐입니다.
- **세계관 항목에는 인물 축이 없습니다.** 어린 노엘도 서약 체계와 금지된 혈통 법을 압니다.
- **`absent.json`은 손으로 만들었습니다.** 추출기로 만든 온톨로지에는 아직 쓸 수 없습니다.
- **미성년 낱말 검사**는 정규식이라 완전하지 않습니다. 프롬프트 규칙과 함께 씁니다. 나이를 모르는 인물은 미성년으로 봅니다.
- **대화가 길어지면 입력이 늘어납니다.** 이력은 최근 20턴까지 넣습니다.
- **말투 예시는 wn01뿐입니다.** 나머지 3편은 말투 칸 없이 호칭과 세계관으로만 말합니다.
- **어린 인물이 독자를 "아저씨"라고 부릅니다**(노엘, 은찬. 시험 답 3개). 스포일러는 아니지만 독자 성별을 넘겨짚습니다. 규칙 한 줄로 고칠 수 있는데 모든 프롬프트가 바뀌어 시험을 다시 돌려야 합니다(약 0.37달러).
