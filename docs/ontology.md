# 장 시간축 온톨로지 1단계 (2026-10-23)

브랜치 `omo/ontology` · 코드 `src/sfqa/ontology.py` · 테스트 `tests/test_ontology.py` · 모델 호출 0회

## 1. 목표와 완료 기준

- **목표:** 독자가 N장까지 읽었을 때, 인물 X가 M장 시점에 아는 것만 코드로 꺼냅니다. 등장인물 채팅 확장안 2번(인물·관계·사건을 장 시간축으로 구조화)의 첫 단계입니다.
- **완료 기준:** 스키마, 합성 웹소설 4편의 정답 변환, 조회 함수, 테스트 통과.
- **결과:** 4편 모두 검사 문제 0건입니다. 전체 테스트는 280개 통과, 2개 건너뜀입니다(추출기 테스트 포함. 건너뛴 2개는 원래 있던 e2e 녹화 테스트입니다).

## 2. 두 겹 차단

- **독자 축:** 공개 장(`reveal_ch`)이 N보다 큰 사실은 누구의 보기에도 넣지 않습니다. 인물이 처음부터 알던 사실도 같습니다.
- **인물 축:** 독자가 읽은 사실이라도 인물이 M장까지 알게 되지 않았으면(`known_by`) 그 인물의 보기에 넣지 않습니다.
- **M은 기본이 N입니다.** M을 앞으로 당기면 "10장 무렵의 카시엘"처럼 과거 시점의 인물과 이야기할 수 있습니다.
- **보기와 평가를 나눕니다.**
  - 보기(`reader_view`, `character_view`)에는 프롬프트에 그대로 넣어도 되는 것만 담습니다.
  - 평가용 `split_facts`는 사실을 셋으로 나눕니다: 인물이 아는 것, 독자만 아는 것, 아직 공개되지 않은 것.
  - 인물이 모르는 사실을 "모르는 척하라"며 프롬프트에 넣지 않습니다. 이런 지시는 새고, 인물이 본 것만 넣으면 누출이 멈춘다는 결과가 있습니다(조사 문서 0. 요약 5번, The Curse of Knowledge).

## 3. 스키마

| 노드 | 담는 것 | 시간 표시 |
| --- | --- | --- |
| 인물 | 이름, 별칭, 호칭, 성별, 나이, 미성년 | 첫 등장 장, 별칭·호칭의 시작~끝 장 |
| 사실 | 문장, 분류, 반전 여부, 근거 줄 | 공개 장, 인물별로 아는 장, 짐작 가능 장 |
| 관계 | 두 인물, 원작 로맨스, 2차 창작 후보 | 상태마다 시작 장, 공개 장, 인물별로 아는 장 |
| 장면 | 시점 인물, 장소, 등장인물 | 장(보기에는 아직 쓰지 않음) |
| 세계관 | 장소, 기관, 마법, 축제, 세계 요약 | 공개 장 |

- 미성년 표시는 독자 진행도와 상관없이 설정 검사에 처음부터 씁니다. 보기에는 넣지 않습니다.
- 근거 줄은 사실 키워드가 든 공개 장의 줄 번호입니다. 인용 검증에 씁니다.

## 4. 정한 규칙

- **설정집에서 옮기지 않은 것:** 성격, 말투, 외모, 뒷이야기, 목표, 성장 줄기(arc), 결말입니다.
  - 화 표시가 없고 뒤 화 내용이 섞여 있습니다. 예: 세실리아 뒷이야기의 "(24화 공개)", 말투 설명의 "(29화~)".
  - 인물 채팅용 말투는 다음 단계에서 화별로 안전한 요약을 따로 만듭니다.
- **판단 근거 메모(note):** 옮기되 보기에는 넣지 않습니다. 작가용 메모라 뒤 화를 가리키는 말이 섞입니다.
- **아직 등장하지 않은 인물:** 이름, 관계, 호칭을 보기에 넣지 않습니다. 그 인물 이야기는 공개된 사실 문장으로만 들어갑니다. 채팅도 첫 등장 장부터 엽니다.
- **배경 관계(이야기 전부터의 관계, 4편 28개):**
  - 설정집 규칙은 "두 인물이 처음 함께 언급되는 화"에 공개한다는 것인데, 그 화가 데이터에 없습니다.
  - 두 인물의 첫 등장 장과 본문에서 처음 함께 나오는 장 가운데 가장 늦은 장으로 잡습니다.
  - 확인: 두 인물이 함께 든 사실보다 추정 장이 이른 것이 7개라, 추정 장 본문을 읽었습니다. 5개는 그 장에 관계가 드러납니다. 2개(테오도르–라파엘 '공적 관계', 하린–강필 '주인 댁 아가씨와 호위무사')는 이미 공개된 직책에서 나오는 내용이라 숨길 것이 없습니다.
  - 늦게 막는 경우는 있습니다. 언급만 되다가 늦게 등장하는 인물(레온, 목연호, 고은재)의 관계입니다. 예: 세실리아–레온 부녀 관계는 1화에 나오지만 레온이 등장하는 45화부터 보입니다. 같은 내용은 사실 문장으로 들어 있습니다.
- **세계관 항목:** 인물별 앎 표시가 없어 인물 보기도 독자 기준으로만 자릅니다. 비밀 기관이나 마법은 인물이 모르는데도 들어갈 수 있습니다(한계).
- **숨은 정체(10/23 추가):** 인물이 아는 사실이라도, 아직 그 인물의 별칭으로 공개되지 않은 이름이 들어 있으면 그 인물의 보기에서 뺍니다.
  - 발견: 테오도르는 f024("세실리아가 '회색 깃털' 서명 편지를 받는다", 6장 공개)를 6장부터 압니다. 그래서 정체가 드러나는 37장 전에도 테오도르 보기에 이 사실이 들어가 있었습니다.
  - 4편에서 실제로 걸리는 것은 테오도르의 '회색 깃털' 2건과 '섭정' 1건입니다. '섭정'은 42~47장에 막는 쪽으로 틀린 경우입니다.
  - 별칭 문자열이 사실 문장에 없으면 잡지 못합니다. 예를 들어 범인이 자기가 한 일을 아는 경우입니다(한계).
- **등장하지 않은 인물:** 첫 등장 장을 비워 둘 수 있습니다(추출기가 언급만 된 인물에 씁니다). 이런 인물은 보기와 채팅에서 빠집니다.
- **상식 표시(10/23 추가):** 추출기가 이야기 속 세상의 상식이라고 표시한 사실은 뒤에 나오는 인물까지 모두 0장부터 안다고 봅니다. 독자 축(공개 장)과 숨은 정체 규칙은 그대로 적용합니다.

## 6. 실행

```bash
uv run python -m sfqa.ontology build
uv run python -m sfqa.ontology show --work wn01-rofan --upto 10 --character cassiel
```

- `show`에 `--at 5`를 주면 인물의 시점을 5장으로 당깁니다. `--json`은 보기를 JSON으로 냅니다.
- `sfqa` 명령에 붙이지 않았습니다. 성능 개선 작업이 `src/sfqa/__init__.py`를 넓게 고치는 중이라, 합친 뒤에 붙입니다.
- 합성 웹소설(`data/synthetic/`)은 아직 커밋 전입니다. 이 브랜치에는 원래 폴더에서 복사해 두었습니다.

## 7. 다음 단계

1. **본문 추출기:** Claude API로 장마다 인물, 사실, 인물별로 아는 장을 뽑아 같은 스키마로 냅니다. 설계와 비용 추정은 `docs/ontology-extract.md`에 있습니다.
2. **추출 평가:** 정답 4편과 비교합니다. 사실 재현율, 공개 장을 앞당긴 비율(누출 위험), 인물별로 아는 장의 정밀도와 재현율을 봅니다.
3. **기준선 비교:** 1~N장 청크 검색, 읽은 장 전체 투입, 장별 인물 요약과 같은 평가셋에서 비교한 뒤 그래프를 어디까지 쓸지 정합니다. 조사 문서의 원칙("그래프는 기준선을 이길 때만 쓴다")입니다.
4. **인물 말투:** 화별로 안전한 말투 요약을 만듭니다.
