# 한계

결과를 읽을 때 함께 봐야 할 것들이다. 날짜별 근거는 [decisions.md](decisions.md)에 있다.

## 정답지와 판정

- **정답지는 사람 검토 전이다.**
  - 56문항과 인물표 88개는 AI 에이전트가 만든 초안이다(`pre-human-review`).
  - 인용이 원문에 글자 그대로 있는지 같은 형식 검사는 코드로 했다(`sfqa gold-check`).
  - 정답이 맞는지, B 질문이 그 N에서 미래를 흘리지 않는지는 사람이 아직 보지 않았다.
- **자동 판정은 키워드 비교다.**
  - 조건문이나 부정을 가리지 못한다.
  - 예: "합격하면 의사가 될 수 있다"(아직 합격 전)를 '합격' 키워드 때문에 정답으로 셌다(f15-2-A).
  - 반대로 같은 뜻을 다른 말로 쓰면 오답으로 셀 수 있다.
- **누출 자동 탐지는 이름과 키워드에 기댄다.**
  - L1: N장 뒤 원문 인용
  - L2: 미래 사실 키워드 조합
  - L3: N장 뒤에 처음 나오는 인물·지명
  - 이름이나 키워드 없이 풀어 쓴 누출("그는 결국 돌아오지 못한다")은 잡지 못한다. 그래서 `review.csv`로 사람이 본다.
- **자동 판정이 정답을 낮게 센다.** test에서 최종 시스템(C4)이 오답으로 판정된 A 9개 가운데 5개는 뜻이 맞고, 2개는 일부만 맞았다(사람 판정 전, 직접 읽어 본 참고값). 사람 판정을 반영하면 A 정답 수가 바뀐다.
- **B 문항의 "답함"은 스포일러와 같지 않다.** "어떻게 되나"류 질문은 N장까지의 처지로 정당하게 답할 수 있다. 스포일러 판단은 누출로 한다.
- **인물표의 흔한 이름은 오탐 위험이 있다.** '김씨'처럼 흔한 이름은 다른 사람을 가리켜도 같은 인물로 잡힌다. 흔한 낱말과 겹치는 '이리'는 뺐다.

## 검색

- **인물의 결말을 묻는 질문을 잘 못 찾는다.**
  - "형보는 어떻게 되나?" 같은 질문의 정답 청크가 31~195위에 있다.
  - 그 인물이 나오는 청크가 수백 개라, 사건을 서술한 청크가 짧은 질문과 가깝게 잡히지 않는다.
  - k를 늘려도 풀리지 않는다.
- **검색 관문은 결과를 본 뒤에 바꿨다.**
  - 처음 정한 recall@6 ≥ 0.8은 17/28로 미달이었다.
  - 사용자 결정으로 recall@18로 바꿔 23/28이 되었다.
  - 관문 판정과 검색 방식 비교에 test 문항도 썼다. 그래서 검색 설계에는 test를 본 영향이 있다. 프롬프트는 dev로만 보았고 고치지 않았다.
- **비교 범위가 좁다.**
  - 임베딩 3종, 청크 크기 3종, dense·bm25·hybrid만 비교했다.
  - 질문 확장(HyDE)은 시도하지 않았다. 모델이 작품을 알면 그 기억 덕을 보는 방식이라, 모르는 작품에 일반화되지 않기 때문이다.

## 모델과 실행

- **모델 조합 하나뿐이다.**
  - 생성 모델 하나(`qwen/qwen3.6-35b-a3b`, MLX 4-bit)와 임베딩 하나(`kure-v1`)로만 쟀다.
  - 다른 모델에서 누출과 정답률이 어떻게 달라지는지는 모른다.
- **같은 요청에도 응답 원문이 완전히 같지 않다.**
  - temperature 0과 seed를 줘도 dev 12문항 중 3개는 응답 원문이 달랐다.
  - 최종 상태와 누출 판정은 같았다.
- **가드 프롬프트(C3)와 코드 검증(C4)의 효과는 측정되지 않았다.**
  - test에서 C2(필터만)의 보인 누출이 이미 0이었다.
  - 이 두 장치가 쓸모없다는 뜻이 아니다. 이번 모델과 작품 조합에서는 검증할 기회가 없었다는 뜻이다.
- **모델의 작품 지식이 적다.** 모델은 「탁류」를 거의 모른다(기억만으로 A 정답 dev 1/6, test 0/22). 그래서 '모델 기억 누출'이 작게 나온 것일 수 있다. 모델이 잘 아는 작품에서는 C2·C3의 누출이 더 클 수 있다.

## 데이터

- **작품 하나, 장 단위다.**
  - 「탁류」 한 작품, 19개 장을 '회차'로 썼다.
  - 장 하나가 4천~4만 자라, 실제 웹툰·웹소설 회차보다 훨씬 굵다.
- **위키문헌 원문의 문제:**
  - 15장에 14장 일부(31줄)가 그대로 중복돼 있다. 고치지 않았고, 정답지 인용은 그 구간을 피했다.
  - 승재가 고아가 된 나이가 3장과 6장에서 다르다.
- **×와 한자 병기:** ×는 검열 삭제와 이름 가림에 함께 쓰였다. 한자 병기는 검색에서만 지운다.
- **표본이 작다.**
  - test 44문항, dev 12문항이다.
  - 비율보다 개수로 읽어야 하고, 조건 사이의 1~2개 차이는 흔들림 안에 있을 수 있다.
