# 생성 모델 비교 기준 (2026-10-14 확정)

실행하기 전에 정한다. 결과를 본 뒤 기준을 바꾸면 날짜와 이유를 아래 "변경 기록"에 남긴다.

## 목적

받아 둔 로컬 생성 모델 5종 가운데 이 서비스에 쓸 모델을 고른다. 클라우드 모델 하나(Claude Sonnet 5.5)를 기준선으로 같이 돌려, 로컬 모델이 어디까지 오는지 본다. 엔진 비교(MLX와 llama.cpp, vLLM)는 결과를 본 뒤 2단계로 정한다.

| 모델 | 형식(엔진) | 크기 | thinking 끄기 |
| --- | --- | --- | --- |
| qwen/qwen3.6-35b-a3b (지금) | MLX | 20.4GB | `reasoning_effort: none` |
| qwen/qwen3.8-27b | MLX | 29.5GB | `reasoning_effort: none` |
| google/gemma-4-26b-a4b | MLX | 28.0GB | 없음 |
| openai/gpt-oss-20b | MLX | 12.1GB | `reasoning_effort: low`(none 불가) |
| google/gemma-4-31b-qat | GGUF(llama.cpp) | 18.9GB | `reasoning_effort: none`(GGUF 판은 기본 켜짐) |
| claude-sonnet-5-5 (기준선, API) | Anthropic API | — | `thinking: between_tools`, effort `high` |

- **Claude 기준선:**
  - 공식 Anthropic SDK로 부르고, 응답 형식은 `output_config.format`(json_schema)으로 강제한다.
  - 키는 `ANTHROPIC_API_KEY` 환경 변수로만 받고, 프로젝트 `.env`(gitignore)에 둔다.
  - 질문과 원문(공유 저작물)이 Anthropic으로 나간다. 서비스 경로는 계속 로컬이다.
  - 순위 후보가 아니라 기준선이다. 로컬 모델 가운데에서 고른다.
  - 서버 쪽 폴백(다른 모델로 넘기기)은 쓰지 않는다. 거절(`stop_reason: refusal`)은 거절로 센다.
- thinking 끄는 방법은 모델마다 `sfqa smoke`로 먼저 확인한다.
- 그다음 dev 12문항으로 응답 형식이 맞는지 본다.

## 평가 데이터

### 1. KLUE-MRC (정답 품질, 공식 벤치마크)

- **표본:** KLUE-MRC validation에서 유형별 80문항씩, 모두 240문항. seed는 20261014다. 라이선스는 CC BY-SA 4.0이다.
  - 유형 1: 바꿔 쓴 표현
  - 유형 2: 여러 문장 추론
  - 유형 3: 지문에 답 없음
- **방식:** 지문을 주고 묻는다(검색 없음). 모델의 독해 능력과 거절 능력만 본다.
- **채점:** 모델 판정 없이 사람이 만든 정답과 비교한다. munjigi의 정규화와 채점 코드를 옮겨 쓴다.
  - 답 있음(유형 1·2): EM(정규화 뒤 정답 중 하나와 같음), 문자 F1
  - 답 없음(유형 3): 보류하면 맞음

### 2. 우리 test 44문항 (스포일러 관문)

- **조건:** C0(기억만), C2(N장 이하 필터만), C3(가드 프롬프트), C4(C3 + 코드 검증)
- **보는 것:** 자동 누출(L1~L4), C 문항 보류, 형식 실패
- A 정답(키워드 채점)은 참고로만 적고 순위에는 쓰지 않는다.

### 3. 속도와 자원

- 응답 시간(중앙값, 95%), 출력 초당 토큰, 첫 로딩 시간, 메모리

## 고르는 규칙 (실행 전 확정)

1. **관문 1(스포일러):** test C4에서 B 자동 누출 0/16, C 보류 5/6 이상, 형식 실패 2/44 이하
2. **관문 2(거절):** KLUE 답 없음 80문항 중 보류 60 이상(75%)
3. **관문 3(형식):** KLUE 형식 실패 5/240 이하
4. **순위:**
   - 관문을 모두 넘은 모델 가운데 KLUE 답 있음 160문항의 EM이 많은 순으로 고른다.
   - 차이가 8문항(5%p) 이내면 같은 것으로 보고, test C4 응답 시간 중앙값이 짧은 쪽을 고른다.
- 모든 수치는 모델 × 유형 표로 낸다. 하나의 점수로 합치지 않는다.

## 이번에 하지 않는 것 (한계)

- 사람 판정과 AI 판정을 하지 않는다. 그래서 우리 과제에서 '뜻은 맞는 정답'과 '이름 없이 풀어 쓴 누출'은 재지 않는다.
- KLUE-MRC는 현대 뉴스와 위키 문체다. 「탁류」 같은 옛 소설 문체의 독해력과는 다를 수 있다.
- 모델마다 1회만 돌린다. 흔들림(dev에서 원문 9/12 같음)이 있으므로 작은 차이는 순위를 정하지 않는다(동률 규칙).

## 실행량

- KLUE: 240문항 × 5모델 = 1,200회(지문 약 1천 자, 회당 2~3초 예상)
- test: 132회 × 새 모델 4종 = 528회. 지금 모델(qwen3.6)은 카세트를 다시 쓴다.
- Claude Sonnet 5.5: KLUE 240회 + test 132회. 2026-10-06 요금($2/$10, 백만 토큰) 기준 약 3~4달러다.
- 모두 약 1.5~2시간이다. 백그라운드에서 모델을 하나씩 올려 순서대로 돌린다.
